# Eco-Sentinel Rwanda 🌿
this project is the green based conservation in rwanda and it include the detection and reforestation

A green-based monitoring system for ecological preservation in Rwanda.

## 🚀 The Mission
This project uses Sentinel Nodes and LoRa technology to protect and monitor Rwanda's natural ecosystems.

## 🛠 Tech Stack
- **Sentinel Node:** C++ (Arduino/RadioLib)
- **Command Hub:** Python (PyLoRa, OpenCV)
- **Database:** MongoDB Atlas
- **Frontend:** React & Leaflet Maps
